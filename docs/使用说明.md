# 油专人拯救计划 · 使用说明

> 版本 **v2.6** ｜ 安装包 `油专人拯救计划-v2.6.apk` ｜ 源码与更新源：`github.com/arkthree74-source/yzyr`

把雨课堂、智慧树、学习通三个平台的作业集中到一屏：打开就知道还有哪些没做、哪几份快到期、哪些已经逾期。底部另一栏「课表」现在也能用了——从学校教务系统导入，按周查看。

---

## 一、第一次使用（3 分钟，跟着提示走就行）

1. 打开 App，会问「第一次用？」，点 **跟着做一遍**，它会带着你一步一步来（也可以点「我自己看看」跳过）。
2. 依次登录三个平台（点「登录」→ 在 App 内打开官方网页登录一次）。**账号密码只在本机，App 不会上传**。
3. 每个平台登录完，会自动带你进「选取课程」：勾上你要盯的课，点「保存」。
4. 回到主页点「同步」，作业就进来了。以后 **每 6 小时自动同步**（这个频率可以在底部「设置」里改），不用再管。

想再看一次引导：右上角菜单 → **新手引导**。

## 二、主页怎么读

顶部蓝色卡片是总览：**未完成 / 今天截止 / 七天内 / 已逾期** 四个数字。

下面两行筛选：

- 第一行：**课程**（弹窗里可勾选多门课，支持全选 / 全不选）｜**全部**｜**今天**｜**7 天**｜**逾期**
- 数字会随筛选变化，看到的就是这个范围内的真实条数。

列表分组顺序：**今天截止 → 明天截止 → 七天内 → 以后 → 没有截止时间 → 已逾期 → 已完成**。

- 每张卡片后的小圆圈点一下 = 标记完成；长按 = 删除。
- 点卡片 = 直接打开对应作业网页。
- 卡片右上角的标签会写「雨课堂 · 课件作业」「超星学习通 · 测验」这类，来源和类型一眼能分辨。
- 右下角 **＋** 可手动加一条作业（老师口头布置的也能记）。
- 底部 **作业 / 课表 / 设置** 三栏切换。

## 三、雨课堂扫码登录小贴士

雨课堂的二维码经常扫不上，尤其是同一台手机又要在 App 里看码、又要用微信扫。点「登录」后 App 会先弹一段说明，两种办法任选：

1. **用另一台设备扫**：另一台手机／平板打开微信，扫本机屏幕上的二维码。
2. **小窗扫码**：把本应用切成小窗或分屏，先给二维码截图；再打开微信「扫一扫 → 相册」，选中那张截图。

登录过程中别把本应用切到后台，否则二维码会刷新失效。登录成功后不用再登，之后一直自动同步。

## 四、自动同步

登录一次就不用再管：

- 选好课程后，App 按你设置的频率在后台自动同步（默认 **每 6 小时一次**，需联网）；
- 频率可改：底部 **设置** → **同步频率**，可选 不自动同步 / 1 / 2 / 4 / 6 / 12 小时 / 每天 / 每两天 / 每周；
- 主页汇总卡下方会写清「**上次同步 11/24 15:17 · 下次自动 11/24 16:19**」，一眼看得出它到底跑没跑；
- 每次打开 App，如果距上次同步超过 2 小时，会立刻补一次；
- 想马上刷新就点顶部「同步」。

**想让它更准时**（vivo、华为、荣耀、小米、OPPO、一加、三星这些系统都要设置一下）：

1. 打开 App → 底部 **设置** → **后台保活**；
2. 照着弹窗里逐项点「去关闭 / 去允许 / 去设置」：
   - **电池优化**：关掉对本 App 的限制（弹窗会直接跳到系统授权页）；
   - **精确闹钟**：允许到点准时叫醒（Android 12 以上才有这一项）；
   - **通知**：允许，登录过期时才收得到提醒；
   - **自启动**（各家叫法不同：华为/荣耀叫「应用启动管理」、vivo/小米/OPPO 叫「自启动」、三星叫「自动运行应用程序」、魅族叫「后台应用管理」）——把本 App 设为**允许**；
3. 想最稳，就在同一弹窗里勾上 **常驻通知**：代价是一条低优先级通知一直挂着，好处是系统几乎不会把你的进程清掉，6 小时闹钟到点就能自己跑。

弹窗里每项后面会写当前状态（「已放行 / 还限制着」），设置完点「刷新状态」可以确认有没有生效。

不做这些也能用，只是系统可能把 6 小时推到七八小时才跑一次，甚至在你把 App 划掉后叫不醒——这是手机省电策略，不是 App 漏了。

**登录过期了怎么办？** 三个平台的登录都是服务端会话，正常情况下 Cookie 会一直保存在手机里（App 每次登录后和每次同步后都会写盘）。如果哪天平台把会话判失效了：

- 清单**不会**被清空——过期的那次同步会跳过该平台，保留原有条目；
- 手机会收到一条通知「有个平台需要重新登录」，点进去重新登录一次即可，其他平台照常。

同步日志在应用私有目录的 `files/sync_diag.log`，闹钟有没有醒在 `files/alarm.log`，每次同步的条数在「设置 → 同步记录」里也能直接看。

## 五、设置页（底部最右一栏）

原来散在右上角菜单里的开关，现在都集中在这里：

| 项目 | 说明 |
| --- | --- |
| 同步频率 | 不自动同步 / 每 1、2、4、6、12 小时 / 每天 / 每两天 / 每周。选「不自动同步」会顺手关掉常驻通知 |
| 后台保活 | 电池优化、精确闹钟、通知、自启动的逐项开关，按机型跳到对应系统页面 |
| 同步记录 | 最近 60 次同步：时间、总条数、各平台条数；登录过期会标出来。可一键清空记录 |
| 选取课程 | 进平台页登录 / 勾课 |
| 新手引导 | 重新从主页带你走一遍（含「打开后台保活」这一步） |
| 清空清单 | 只清本机记录，不动平台上的作业 |
| 检查更新 | 联网检查新版本；打开 App 时也会自动查一次，有新版直接弹窗提醒 |
| 更新记录 | 每个版本改了什么，一条条列好，离线也能看 |
| 这个 App 干了什么 | 一句话说明：不保存账号密码，只在本机存登录状态 |

**同步记录**是判断「到底有没有自动同步」最直接的证据：每次同步都会留下一条，比如 `11/24 15:16 · 50 条 · 雨课堂 34 · 智慧树 13 · 超星学习通 3`。

**关于更新**：每次打开 App，它会在后台花几秒钟问一下有没有新版本；有的话直接弹窗，弹窗里列的就是这个版本改了什么。点「以后再说」，同一个版本 24 小时内不再打扰你。更新源先问 GitHub 接口、失败再走 CDN（CDN 可能慢 12 小时，所以只当兜底）。

## 六、课表（从学校教务系统导入）

1. 底部切到 **课表**，点右上「导入课表」。
2. App 会打开学校教务系统（`jwxt.upc.edu.cn`，走学校统一身份认证）。已登录的话会直接进主页；没登录就先登录。
3. 点右下角 **打开课表查询**，App 会自动抓到「学生个人课表」并解析，提示「已导入 N 节课」。
4. 回到课表页就能看到格子表了：**周日 → 周六**横排（学校教务系统也是一周从周日算起），左边是节次和上课时间。

**按周看**：

- 顶上「**第 12 周 · 11/22 - 11/28**」，`‹` `›` 切上一周／下一周，「本周」一键回到当前周；
- 只显示**这一周真正要上的课**（单双周、`1-17周`、`1,4,7-9周` 这些写法都认），所以换周次课表会变，这是正常的；
- 点某个格子，弹出「课程 · 教室 · 教师 · 周次」。

**周次不准怎么调**：点一下每周标题（比如「第 12 周」），会弹出「第 1 周的周日」，填你学校校历第 1 周的那个周日日期（默认按 2026-09-06 算），保存后周次立刻重算。

> 目前只适配了中国石油大学（华东）的强智科技教务系统；换学校需要改解析规则。

## 八、常见问题

**Q：同步后条数没变？**
A：说明这段时间没有新作业，或者被勾掉的课本来就没作业。可在「选取课程」里确认「已选 N 门」。

**Q：某个平台一直显示「已选 N 门 · 点「登录」把页面打开一次」？**
A：这个平台要把页面真正打开过一次，登录凭证才会存到手机上。点右侧「登录」→ 进去登录 → 点右下角「选取课程」，之后再同步就正常了。

**Q：某个平台 0 条？**
A：先确认那个平台在「选取课程」里既登录过、也勾了课程。学习通如果刚开学还没有临期任务，也会是 0 条。

**Q：登录过期了怎么办？**
A：进「选取课程」点对应平台的「登录」重新登录一次，再回主页同步。清单不会因为这个被清空。

**Q：雨课堂二维码扫不上？**
A：用另一台设备扫，或者把自己小窗化后先截图、再到微信「扫一扫 → 相册」里选图；期间别切后台。详见第三节。

**Q：为什么有时几小时没更新？**
A：系统省电策略会延后后台任务。底部 **设置** → **后台保活**，把电池优化、精确闹钟、通知、自启动逐项允许（各家叫法不同），必要时勾上「常驻通知」。主页汇总卡下方的「上次同步 / 下次自动」能直接看出它上一次是什么时候跑的。

**Q：我把 App 从后台划掉，还会自动同步吗？**
A：取决于系统。多数国产系统划掉后就不再给广播，需要「自启动」里允许本 App（设置 → 后台保活 → 自启动）；勾了「常驻通知」的话进程基本一直在，划掉也不太影响。

**Q：怎么确认它真的在自动同步？**
A：底部 **设置** → **同步记录**，每次同步都会留一条（时间 + 总条数 + 各平台条数）。如果列表停在你上次手动点「同步」的时间，说明系统在拦后台任务，去「后台保活」逐项放开。

**Q：同步太频繁 / 想更省电？**
A：底部 **设置** → **同步频率**，改成「每 12 小时」「每天一次」甚至「不自动同步」；选「不自动同步」后需要手动点顶部「同步」。

**Q：主页那行「上次同步 … · 下次自动 …」是什么意思？**
A：上一次真正完成同步的时间，和系统里已经排好的下一次唤醒时间。如果「上次同步」一直停在很久以前，就是被系统省电策略拦了，按上一条去开白名单。

**Q：课表某一周是空的？**
A：正常。那周这门课没排（比如只上前 11 周的课）。用 `‹` `›` 换周次能看到变化。

**Q：课表周次对不上？**
A：点周次标题（如「第 12 周」），把「第 1 周的周日」改成学校校历上的日期即可。

**Q：会不会把我作业点成「已完成」？**
A：不会。App 只读不写，勾选状态只存在本机。

**Q：换了手机怎么办？**
A：重新登录 + 重新选课 + 重新导入课表即可，数据不跨设备同步。

**Q：新手引导还能再看一次吗？**
A：能，右上角菜单里点「新手引导」就会重新从主页开始带你走一遍。

## 十、源码与发版

- 仓库：<https://github.com/arkthree74-source/yzyr>
- 目录：`app/` 安卓源码 ｜ `docs/使用说明.md` 本文档 ｜ `releases/` 安装包 ｜ `update.json` 更新清单
- 仓库里**不含**签名文件与 `local.properties`，别人 clone 下来会用 debug 签名编译，无法覆盖安装正式包。

发一个新版本只需要四步：

1. `app/build.gradle.kts` 里把 `versionCode` +1、`versionName` 改成新版本号；
2. 编译出 release APK，文件名改成 `yzyr-vX.Y.apk` 放进 `releases/`；
3. 改 `update.json`：`versionCode`、`versionName`、`url`、`size`、`sha256`、
otes`；
4. 提交后刷新 CDN 缓存：打开 `https://purge.jsdelivr.net/gh/arkthree74-source/yzyr@main/update.json`（浏览器打开即可，返回 `"status": "finished"` 就生效）。

之后所有装了 2.3 及以上版本的人，在「设置 → 检查更新」里就能直接升级。
